# Changelog

Reco+ versions, newest first. Each line is the changelog shown by Jellyfin's plugin catalogue.
Compatibility: see the Jellyfin range of each version below (`targetAbi` in `manifest.json`).

## 1.2.0 — New releases, country of each account, title origin, user page, daily lists

- **1.2.0** (Jellyfin 12.2–12.4) — a New releases row shows what has just come out in each account's country (theaters, digital, TV), movies and series. Each account's country is detected (browser time zone and languages, Jellyfin language, usual subtitles) or chosen: one country, several, or international. A new Title origin factor gently lifts titles in a language and from a country familiar to the account. With the Plugin Pages plugin, every user gets a Reco+ page to set their country and titles outside the library. Popular becomes Most popular of all time (TMDb's most voted titles), and every current list renews each day (adjustable). A title you requested goes on top of For you and of banners such as Media Bar Enhanced for 3 days when it arrives, then takes its normal place. Fixes: Popular and New releases only listed titles in the server's language (Seerr filter); switching extended mode back on now recomputes at once; the settings page uses Jellyfin's own look, the full width and no folded sections. Security: Seerr and the webhook never follow redirects, Seerr answers are size-limited, the secrets file is private.

## 1.1.3 — Fixes

- **1.1.3** (Jellyfin 12.2–12.4) — rows were missing for some accounts. An account that had saved its own Home Screen Sections choice never saw the Reco+ rows added to the Home Screen Sections table afterwards (Trending, Popular…): they are now ticked for it once, and stay unticked if it unticks them. The Preview tab says which rows Home Screen Sections does not show to an account. A row with no title from the library (Upcoming, or a current list whose library titles the account has already watched) stayed empty: its titles outside the library are now shown.

## 1.1.2 — Fixes

- **1.1.2** (Jellyfin 12.2–12.4) — calibration no longer runs out of memory on larger servers — each case keeps only what that account's ranking reads, and the calibration caches have a size limit (measured on a MovieLens server: peak memory 4.3 GB → 1.2 GB, 54 → 13 minutes, same result). The options of the settings level selector are readable again when the list is open. Security: the Seerr API key and the Gotify token are no longer sent along when Seerr or the webhook answer with a redirect (the error now names the address to save instead), and Seerr answers are size-limited.

## 1.1.1 — Fix

- **1.1.1** (Jellyfin 12.2–12.4) — "Recompute now" clicked while a full computation was already running was silently ignored, so new settings (or a Seerr connection just saved) only applied at the next computation. The request now waits and runs right after the current computation.

## 1.1.0 — 1.1 series

- **1.1.0** (Jellyfin 12.2–12.4) — start of the 1.1 series. From now on a version groups a coherent set of changes (1.minor.patch: features in a minor version, fixes in a patch) instead of one version per change, so updates are fewer and each says more. Same features as 1.0.55 — German and Spanish interface, visual preview, discovery boldness slider, reasons on title pages, three settings levels, honest calibration gains; the full history is in CHANGELOG.md. The catalogue no longer lists 1.0.36, which was never released.

## 1.0.43 – 1.0.55 — Settings levels, reasons, discovery boldness, German and Spanish, visual preview

Jellyfin 12.2 and later 12.x.

- **1.0.55** (2026-11-23) — internal cleanup — TMDb identifiers are read in one place, strictly (a malformed one is now ignored instead of failing that part of the computation), the calibration's two bootstrap computations share one implementation, and duplicated settings reads are gone. Recommendations are unchanged.
- **1.0.54** (2026-11-23) — the interface is now also in German and Spanish (settings page, home rows, cards, reasons and notifications), chosen automatically from each person's Jellyfin language or set in the plugin; a text missing in either falls back to English. The settings page also drops the remaining technical terms from its essential and advanced levels.
- **1.0.53** (2026-11-23) — the Preview tab now shows what an account actually sees — its home rows in order, as posters, with titles outside the library in their place and, under each title, why it is proposed — instead of plain lists of names.
- **1.0.52** (2026-11-23) — extended mode no longer proposes re-edits of existing films (The Godfather Trilogy: 1901-1980 came out as a "hidden gem"), and TMDb keywords that describe how a title was made rather than what it is about (based on a novel, after-credits scene, sequel, remake…) no longer count as themes to explore.
- **1.0.51** (2026-11-23) — calibration is more honest about its gains — the step along each method's path and the method itself were chosen on the same cross-validation measurements that then reported the gain, which flatters the winner (the best of several noisy draws). The announced gain and the recommendation now come from the whole choice made again without each group of accounts and judged on it (no extra training).
- **1.0.50** (2026-11-23) — new "Discovery boldness" slider in the Extended mode tab, from cautious to bold: it sets in one move the minimum TMDb votes and rating of the exploration, the genres explored for hidden gems and the daily randomness (the middle keeps today's values). Measured with a real Seerr, bold divides the median votes of the proposed titles by 2 to 7 while their average rating and the fit with each account's tastes stay the same.
- **1.0.49** (2026-11-23) — in extended mode, outside-library titles on the home screen use Jellyfin Enhanced's own cards and Request button again — JE 12.17 only loads its Seerr module on its own pages, so Reco+ now asks JE's loader for it (Reco+'s cards remain the fallback without JE or without Seerr). The web page Reco+ adds its script to is now revalidated on every load, so a browser no longer keeps an old script after an update.
- **1.0.48** (2026-11-23) — discovery from authors (extended mode) is more to the point — two parts of the same saga no longer count as two reasons to like its director, studio or themes (Harry Potter 1 and 2 no longer bring Chris Columbus's whole filmography), and an author's works must share two genres with the liked titles that led to them (Andrew Stanton, found through Toy Story and Finding Nemo, leads to A Bug's Life, no longer to John Carter or Obi-Wan Kenobi).
- **1.0.47** (2026-11-23) — new setting Home › Rows › "Repeat across rows" (off by default): a title already shown in one row may come back in another when it is among that row's best titles for what the row is about, never in the row right above, never as its first card, in a limited number of rows; the rest of the ranking never repeats "For you". Measured on a realistic bench of 30 accounts, it barely changes relevance, so it stays a matter of taste. The integration test now also opens the home screen in a real browser, with and without extended mode.
- **1.0.46** (2026-11-23) — the page of a title opened from a Reco+ row now says, in a discreet grey line under its name, why it was proposed ("Because you liked X", "Sequel to X", "New episodes", "Trending this week", "Recently added") — only when the reason is clear, never on the home cards; outside-library cards keep their own reason.
- **1.0.45** (2026-11-23) — the settings page gets three levels — essential (default), advanced, expert — so it shows what matters first while keeping every fine setting; the State tab opens with a health summary and a start-up checklist with one-click actions (run the first computation, add the Reco+ rows to Home Screen Sections and enable it, connect Seerr); after Save, a banner offers to recompute and shows the Preview as soon as it is done.
- **1.0.44** (2026-11-23) — titles in a Seerr watchlist were proposed again as outside-library recommendations when their details were not cached yet (each account's requests and watchlist are now always excluded); a later part of a saga outside the library is only proposed once every earlier part, in the library or not, is seen (no more part 5 to someone at part 2); a suggestion found from a title the account only requested now says "Because you're waiting for X" instead of "Because you liked X"; accounts without any known taste no longer get random "little-known gems" from all of TMDb.
- **1.0.43** (2026-11-23) — settings could not be saved after enabling extended mode (issue #44) or after applying a coordinate-search calibration — a re-enabled field failed the browser's validation silently; the page no longer blocks and the server keeps every value in range; titles pinned at the top (new episodes, next part of a saga) now respect the list filters; a new episode triggers a recomputation like other additions; "More like this" puts the next part first from the same sagas as the rest of the plugin (TMDb collections, name rule); free mix no longer favours library titles for brand-new accounts; deleted Jellyfin accounts are forgotten; a failed computation and an unreadable watch history now raise an alert; the first-play register is bounded.
